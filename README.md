# control-de-ventas
- __Lógica__: Python
- __Interfaz__: Streamlit
## Configuración
> Ubicación
```bash
cd football-analytics
```
> Crear entorno virtual
```bash
python -m venv venv
```
> Activar entorno virtual
```bash
venv\scripts\activate
```
> Instalar dependencias
```bash
pip install -r requirements.txt
```
> Iniciar aplicación
```bash
streamlit run app/main.py
```
